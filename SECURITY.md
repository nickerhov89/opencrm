# Security policy

OpenCRM handles customer and sales data. Please do **not** disclose a vulnerability in a public issue or include real customer data in a report.

Use GitHub's **Security → Report a vulnerability** feature in this repository to send a private report. Include the affected version, a minimal reproduction using fictional data, and the potential impact. Maintainers will assess the report and coordinate a fix and disclosure.

The first public release is `0.1.0`; security fixes will be provided for the current release line when feasible. Run the app behind HTTPS, keep backups outside the host, and update dependencies regularly.
